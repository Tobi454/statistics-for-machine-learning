# Statistics for Machine Learning

A collection of statistics concepts, examples, and Python implementations for building a strong foundation in Machine Learning.

## Topics Covered

- Descriptive Statistics
- Variance and Standard Deviation
- Percentiles, Quartiles and IQR
- Z-Scores and Standardization
- Correlation
- Covariance
- Sampling
- Statistical Inference
- Confidence Intervals
- Hypothesis Testing
- P-Values
- Type I and Type II Errors
- Statistics with Python

## Tools Used

- Python
- NumPy
- Pandas
- Matplotlib
- SciPy
- Scikit-learn
